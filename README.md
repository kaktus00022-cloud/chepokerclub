# CHEPOKER CLUB — сайт для GitHub Pages

Статический одностраничный сайт без сборщика и CMS. Достаточно загрузить содержимое этой папки в репозиторий GitHub и включить GitHub Pages.

## Файлы

- `index.html` — структура и весь текст сайта
- `styles.css` — стили и адаптив
- `script.js` — мобильное меню, анимации, поведение шапки
- `assets/` — фотографии, видео, логотип и favicon

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **все файлы и папку `assets` в корень репозитория**.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, папка: `/ (root)`.
6. Сохраните настройки. Через несколько минут GitHub покажет адрес сайта.

## Что можно менять без верстальщика

### Ссылки
В `index.html` найдите:
- `https://t.me/chepoker_bot`
- `https://chepoker.poker-soft.ru/`
- `https://instagram.com/chepoker_club`

и замените при необходимости.

### Тексты
Все тексты находятся прямо в `index.html`. Блок «следующий турнир» специально отсутствует: сайт не требует регулярного обновления дат, времени и площадок.

### Фото и видео
Файлы лежат в `assets/`. Можно заменить изображение, сохранив то же имя файла — тогда HTML менять не потребуется.

Hero-видео: `assets/hero.mp4`. Оно специально сжато для веба примерно до 720×1280 / 30 fps, чтобы GitHub Pages загружался быстрее.

## Важно по юридическому тексту

На сайте используется аккуратная формулировка: игры проходят без денежных ставок и денежных призов. Перед коммерческим запуском рекомендуется проверить фактическую механику всех взносов, бонусов и призов с профильным юристом, чтобы сайт точно соответствовал реальному формату клуба.
